# QQCross — подключение режима «Играть с ChatGPT»

Режим уже подключён к отдельной Supabase Edge Function `qqcross-ai-turn`. Функция требует авторизованную Supabase-сессию, проверяет лимит запросов и обращается к OpenAI только на сервере. API-ключ не хранится в браузере.

## Что должен настроить владелец проекта (совместно со взрослым)

1. В Supabase Dashboard открой проект **QQCross**.
2. В разделе **Authentication → Sign In / Providers** включи **Anonymous Sign-Ins**. Это нужно, чтобы гостевой игрок мог получить защищённую сессию без регистрации по почте.
3. В разделе **Edge Functions → Secrets** добавь секрет:
   - Name: `OPENAI_API_KEY`
   - Value: действующий OpenAI API key.
4. Не добавляй ключ в `app.js`, HTML, GitHub, переписку или скриншоты. Не публикуй его и не передавай другим людям.
5. Учитывай, что запросы к OpenAI могут быть платными. Настройку ключа и контроль расходов должен выполнять владелец проекта совместно со взрослым.

## Ограничения и проверка

- Edge Function: `qqcross-ai-turn`, JWT verification включена.
- Лимит: не более 30 запросов на пользователя за один час.
- Для каждого хода модель предлагает ответ по подсказке; клиент сверяет его с настоящими буквами сканворда, прежде чем засчитать ход.
- Если ключ отсутствует, функция возвращает понятную ошибку, а не подменяет ChatGPT локальным ботом.
- После добавления секрета открой опубликованное приложение, выбери «Играть» → «Играть с ChatGPT» и проверь первый ход.

Обычный одиночный режим и игра с друзьями не зависят от этого ключа и продолжают работать отдельно.
