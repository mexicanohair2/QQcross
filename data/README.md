# Словарь QQCross

Файл `scanword-dictionary.json` — основной словарь игры. Он должен содержать JSON-массив объектов. Игра загружает его при запуске.

Формат записи:

```json
{
  "answer": "ФРАНЦИЯ",
  "emoji": "🇫🇷"
}
```

Для обычных слов вместо `emoji` указывается текстовая подсказка:

```json
{
  "answer": "РОМАШКА",
  "clue": "Цветок с белыми лепестками"
}
```

Можно также использовать поле `question` вместо `clue`. Для стран используются только эмодзи соответствующих флагов — текстовые вопросы о флагах не нужны. Ответом остаётся название страны.

Ограничения: ответ от 2 до 12 букв; поддерживаются русские и латинские буквы. Не добавляйте категории: все записи перемешиваются вместе.

В актуальной версии словарь содержит 2 243 записи и 2 057 уникальных ответов. Все записи перемешиваются вместе; категории не используются. Перед публикацией проверяйте ответы, подсказки и индексы шаблонов.


## Общая русская база QQCross

`russian-words-100000.json` — общий словарь из ровно 100 000 уникальных русских слов. В него обязательно включаются все допустимые слова для текущего Wordle и все многобуквенные ответы текущего сканворда, затем база дополняется частотными русскими леммами. Классический поиск и режим составления слов используют общую базу. Wordle продолжает применять собственный фильтр пятибуквенных слов и неизменённую игровую механику. Сканворд и кроссворды используют только те записи, для которых есть проверенная подсказка; новые слова не получают выдуманных определений автоматически.


## Распределение слов между играми

Проверенная сборка общего словаря содержит ровно 100 000 уникальных русских слов. В неё включены все 26 239 допустимых пятибуквенных слов Wordle и все 2 057 уникальных многобуквенных ответов сканворда. Wordle по-прежнему использует собственные списки из 26 239 допустимых слов и 5 348 слов для загадывания; его правила и интерфейс не менялись. Сканворд использует отдельный проверенный банк из 2 243 записей с подсказками (2 057 уникальных ответов). Классический поиск и Word of Wonders используют частотный список из 25 000 слов с фильтрами по длине. CodyCross и сканворд используют только проверенные подсказки. Кроссворды используют проверенные формулировки из существующего банка подсказок; остальные слова общей базы не превращаются в ответы с выдуманными определениями. Для расширения банка CodyCross и сканворда нужны дополнительные проверенные русские определения.


## Частотный словарь для повседневных игр

`russian-words-common-25000.json` — ровно 25 000 уникальных частотных русских слов, отсортированных по частоте употребления. Этот список используется в поиске слов и Word of Wonders; полный словарь из 100 000 слов сохранён отдельно. Слова из частотного списка не превращаются автоматически в вопросы: для кроссвордов нужны проверенные определения.


## Лицензии общей базы

Базовый список QQCross собирается скриптом `scripts/build_russian_lexicon.py` из двух источников: частотный корпус Digital Pushkin Lab (CC0-1.0) и список danakt/russian-words (MIT). Все 100 000 записей нормализуются к кириллице; перед публикацией проверяются точное количество, уникальность и допустимый алфавит. Это словарь для поиска и проверки слов, а не банк определений: подсказки для сканвордов не генерируются автоматически.
