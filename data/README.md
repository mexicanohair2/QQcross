# Словарь QQCross

Файл `scanword-dictionary.json` — основной словарь игры. Он должен содержать JSON-массив объектов. Игра загружает его при запуске.

Формат записи:

```json
{
  "answer": "ФРАНЦИЯ",
  "emoji": "🇫🇷"
}
```

Для обычных слов вместо `emoji` указывается текстовая подсказка:

```json
{
  "answer": "РОМАШКА",
  "clue": "Цветок с белыми лепестками"
}
```

Можно также использовать поле `question` вместо `clue`. Для стран используются только эмодзи соответствующих флагов — текстовые вопросы о флагах не нужны. Ответом остаётся название страны.

Ограничения: ответ от 2 до 12 букв; поддерживаются русские и латинские буквы. Не добавляйте категории: все записи перемешиваются вместе.

В актуальной версии словарь содержит 1195 записей. Все записи перемешиваются вместе; категории не используются. Перед публикацией проверяйте ответы, подсказки и индексы шаблонов.


## Общая русская база QQCross

`russian-words-50000.json` — общий словарь из ровно 50 000 уникальных русских слов. В него обязательно включаются все допустимые слова для текущего Wordle и все многобуквенные ответы текущего сканворда, затем база дополняется частотными русскими леммами. Классический поиск и режим составления слов используют общую базу. Wordle продолжает применять собственный фильтр пятибуквенных слов и неизменённую игровую механику. Сканворд и кроссворды используют только те записи, для которых есть проверенная подсказка; новые слова не получают выдуманных определений автоматически.
