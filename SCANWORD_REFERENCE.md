# QQCross scanword reference specification

Reference asset (Dropbox): `/Screenshot_20261105_010300_app_kryds_android_MessagingUnityPlayerActivity.jpg`

## Confirmed visual structure
- The reference board is a square **13 columns × 13 rows** grid.
- Cells are square, with a small, consistent gap.
- The grid is the main element in the middle of the game screen.
- The player/status header and scores sit above the grid.
- The letter rack and check/confirm control sit below the grid.
- Clue cells appear on the top and left edges; top-edge clues start downward, left-edge clues start to the right.
- Direction indicators are small and point right or down.
- The clue text/content is generated by QQCross and must remain our own; the reference controls the visual structure and placement, not the actual clue wording.

## Implementation guardrails
- Never change the grid dimensions, board proportions, cell proportions, spacing, clue placement rules, arrows, or vertical composition without checking this reference first.
- Keep the board large and centered in the available phone game area; it must not shrink to a small tile or force horizontal/vertical scrolling.
- Do not add left/up clue directions unless the reference is re-inspected and clearly shows them.
- Keep the score area above the board and letter rack/confirm control below it.
- Keep clue contents generated from QQCross data; do not copy the reference game's questions or answers.

## Verification note
The reference image was located in Dropbox and its overall grid/screen structure was inspected in a browser. Exact pixel coordinates for every interior clue cell have not yet been transcribed into a fixed coordinate template. Do not claim an exact cell-by-cell placement match until that map has been measured against the image.
